# HR_REPORT

An interactive HR Analytics Dashboard built using Microsoft Power BI to analyze employee attrition, workforce demographics, salary distribution, and job satisfaction. The dashboard provides department-wise insights across Human Resources, Sales, and Research & Development, helping identify attrition patterns and support data-driven HR decision-making.
